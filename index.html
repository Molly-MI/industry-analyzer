行业分析工作台

Key 仅存在浏览器 localStorage，请求直发所填地址的 /v1/messages（Anthropic 原生格式）。 三方平台要求：支持 Anthropic 原生 Messages 接口和浏览器 CORS；模型 ID 按平台写法填（如 anthropic/claude-opus-5）。「联网核实」用的是 Anthropic 服务端 web_search 工具， 平台不透传时会自动降级为无检索模式（届时报告不再有 A 档）。安全分类器的服务端 fallback（fallbacks:"default"）仅在官方地址下启用。 一次完整五步分析（含检索）token 消耗较大，请留意右上角用量。
