# 行业分析工作台 · 证据分级版

单文件 Web 应用：输入一个行业名称，按固定的五步 prompt 链自动生成一份**带证据分级（A/B/C）的行业分析报告**，并可进入"从业者拷问"模式检验你对报告的理解。浏览器直连 Claude API，无构建、无后端、无第三方依赖。

## 特性

- **五步分析链**：边界切分 → 产业链分层 → 钱流/货流/用户流 → 议价能力（可验证的量）→ 约束/节奏/异常 + 盲区清单，每步携带全部上下文串行生成
- **证据分级纪律**：A 档必须联网检索核实到具体文件（文件名+年份），检索不到就降级或写「未获取」；C 档只进待验证清单；禁"较强/较弱"式模糊表述
- **联网核实**：使用 Anthropic 服务端 `web_search` 工具，自动处理 `pause_turn` 续传
- **从业者拷问模式**：模型扮演从业 12 年的内行，专挑报告里 B/C 档和「未获取」字段反问，15 轮后给诊断
- **三方中转平台支持**：自定义 API 地址、`Authorization: Bearer` 认证、带前缀的模型 ID（如 `anthropic/claude-opus-5`）；网关不认识的可选参数自动剥离重试
- **健壮性**：断流自动重试（半截文本回滚，不重复）、失败步骤断点续跑（不用从头重烧 token）
- 流式渲染、token 用量实时统计、一键导出 Markdown 报告

## 使用

```bash
python3 -m http.server 8123 -d .
```

打开 http://localhost:8123 → ⚙ 设置里填 API Key（仅存浏览器 localStorage）→ 输入行业名称开始。

默认模型 `claude-opus-5`。一次完整五步分析（含十几次检索）token 消耗较大，请留意右上角用量。
